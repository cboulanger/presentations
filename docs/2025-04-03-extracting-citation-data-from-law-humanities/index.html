Compare our tool with Grobid's performance - Offer more training data to Grobid (and others) - *but what exactly is performance?* --- ## Llamore: Presentation, Evaluation and Results David Carreto Fidalgo --- ### Llamore **L**arge **LA**nguage **MO**dels for **R**eference **E**xtraction - **What is it?** A python package to *extract citation data* from raw input *text or PDFs* using LLMs (multimodal) and to *evaluate* the extraction performance. :::info **Text / PDFs ---> References (TEI, XML)** **Gold References ---> Evaluation metric (F1)** ::: - **Objectives** - light weight: less than 2000 lines of code - compatibility with open and closed LLMs <!-- .element class="fragment" --> --- ### How does it work? ```bash pip install llamore ``` #### Extraction ```python from llamore import GeminiExtractor, OpenaiExtractor extractor = GeminiExtractor(api_key="my_api_key") references = extractor(pdf="/path/to/my.pdf") # or references = extractor(text="My raw input string") # Export to TEI biblStructs references.to_xml("./references.xml") ``` #### Evaluation ```python from llamore import F1 f1 = F1(levenshtein_distance=0) f1.compute_macro_average(references, gold_references) ``` --- <!-- .slide: class="two-columns-header-footer" --> <div class="header"> ### Evaluation - Compare references Precision = Matches / Predicted Elements Recall = Matches / Gold Elements **---> F1-Score** </div> <div class="left"> Extracted Reference ```json { "analytic_title": "Citizenship and Feminist Politics", "monographic_title": "Citizenship", "authors": [ { "forename": "A", "surname": "Phillips" } ], "publication_date": "1991", } ``` </div> <div class="right"> Gold Reference ```json { "analytic_title": "Citizenship and Feminist Politics", "monographic_title": "Citizenship", "authors": [ { "forename": "A.", "surname": "Phillips" } ], "publication_date": "1991", "cited_range": "77" } ``` </div> --- ### Evaluation - Align references | | Gold1 | Gold2 | | --- | --- | --- | | **Ref1** | 0.1 | 0.9 | **Ref2** | 0.9 | 0.2 | **Ref3** | 0.8 | 0.0 Maximize the total F1-score while ensuring a unique assignment :::info **Unbalanced Assignment Problem** ::: <!-- -
